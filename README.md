# Giftly: Santa's little agent for real giving

*Follow your gift from click to child. Your money moves only when the gift arrives.*

Hackathon prototype for the PayPal AI Hackathon 2026. Work in progress. The full README (architecture, real vs simulated, AI disclosure) comes in the final step.

## Run locally
```bash
npm install
cp .env.example .env   # Windows: copy .env.example .env
npm run dev
```
Open http://localhost:3000 and http://localhost:3000/api/health
